成本计算器

输入用量、缓存命中率与正常 / 夜间 Token 占比，计算每个模型的预估花费。夜间折扣占比的 Token 对 GLM-5.2 按 7 折计价，对 DeepSeek-V4.1-Flash / DeepSeek-V4.1-Flash-1017 按 5 折计价。支持缓存命中价的模型按命中率拆分正常 / 缓存输入花费；不支持者全部按正常输入计。

Tokens 计算器

输入预算、缓存命中率、输入 / 输出 Token 比例与正常 / 夜间 Token 占比，计算每个模型可使用的输入 / 输出 Token 量。夜间折扣占比的 Token 对 GLM-5.2 按 7 折计价，对 DeepSeek-V4.1-Flash / DeepSeek-V4.1-Flash-1017 按 5 折计价；占比 > 0 时额外展示按正常价、按折扣价计算的合计 Token。

说明：GLM-5.2 / GLM-5.3 / DeepSeek-V4.1-Flash / DeepSeek-V4.1-Flash-1017 支持缓存命中价。夜间折扣时段（北京时间 21:00–08:00）对 GLM-5.2 的全部目录价（输入、缓存、输出）乘以 0.7，对 DeepSeek-V4.1-Flash / DeepSeek-V4.1-Flash-1017 乘以 0.5，GLM-5.3 不参与折扣。成本计算器展示的是花费金额而非单价：正常输入花费=输入Token×输入价×(1−命中率)，缓存输入花费=输入Token×缓存命中价×命中率，输出花费=输出Token×输出价。
